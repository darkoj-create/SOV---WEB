SOV ADMIN 1.4.55a — OTVARANJE U ANDROID STUDIJU

1. Raspakiraj cijeli ZIP u novi folder, npr. D:\SOV-app builds\sov-admin-1.4.55a
2. U Android Studiju odaberi File > Open.
3. Otvori folder u kojem su settings.gradle.kts, build.gradle.kts i folder app.
4. Pusti Gradle Sync.
5. Ako Android Studio ne napravi local.properties automatski, kopiraj local.properties.example
   u local.properties i upiši svoj sdk.dir. Pravi SOV_APPS_SCRIPT_KEY nemoj spremati u Git.
6. Za provjeru napravi Build > Clean Project, zatim Build > Build APK(s).
