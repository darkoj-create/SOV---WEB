Jedno mjesto za provjeru synca.

Ova stranica je usklađena s web buildom v6.1.4. Oružarstvo ima single boot: lokalni JSON odmah, Supabase refresh u pozadini. Prvo čita centralni Supabase RPC sov_system_health(), a zatim po potrebi detaljne fallback provjere: karta/baza objekata, puni detail objekta, nacrti, izleti, Oružarstvo, Field Tracking Lite, Trip Assets/paketi za teren, role, novosti CMS, user predaje članaka, arhivarske predaje i Webmaster-only zaštitu. Ne mijenja podatke.

Pravilo za buduće buildove

sync-status.html je dio builda

Od v6.1.4 ova stranica se ažurira uz svaki relevantan web build: verzija, novi moduli, SQL potrebe, forma predaja, endpointi, centralni system health RPC i DB cleanup registry. Tehnički status ostaje samo Webmasteru.

Dashboard preview je samo vizualni filter na dashboardu. Ne mijenja stvarne role i ne daje pristup zaštićenim stranicama.
